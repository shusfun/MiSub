保护性节点缓存：按源显式开启；拒绝大缓存异常缩水与仅本机公告节点，保留最近成功库存与用量。旧缓存受时限约束并显示警告，不能冒充新观测。
入站启停：要求 inbound.enabled.v1。停用经 Gate 回执后撤下订阅并关闭该入站客户端；不更换凭据，不影响其他入站。重启及旧接口省略 enabled 均保留状态；重新启用仍须符合授权、到期和额度规则。实测状态见实施记录。

04安全与判断

规则执行 · 模型辅助

人的身份

管理员登录二次验证；后端角色检查；用户数据按身份隔离。

登录限速、会话撤销、恢复机制。2FA 与设备配对是两套认证。

设备的身份

VPS 发起配对；一次性短时凭证；独立设备身份，可单独撤销。

主动出站连接、操作白名单、拒绝重放与跨设备指令。

行为的证据

记录谁、何时、对哪台设备、做了什么，以及执行结果。

中心与本地留痕；敏感信息脱敏。未知状态不能显示正常。

Laya：脱敏事件 → 远程 API → 分类与告警优先级。密钥仅后台持有；模型不能授予权限或直接执行命令；超时仍保留规则告警与事件记录。评分不是攻击事实，需真实样本验证。
DNS-01 清理边界

外部创建前持久登记归属；只删除名称、TXT 值与随机归属标记全部一致的记录。中断后恢复检查，失败保留未知 / 失败状态；管理员可重试。凭据在未清理时禁止删除，确认清理后移除敏感恢复材料。实际 DNS 服务缺配置时，受控测试不能替代真实签发验收。

公开目录安全适配

目录只引用显式发布的文本页面；卡片仅标题、简介与本地公开路径。默认不分享，主题采用固定预设。私有节点、用户订阅令牌与未发布内容不可匿名导出；完整订阅目录与其余上游交互保持待迁移。

只读内核诊断

仅 core.diagnostics.v1 设备接收 core.inspect；固定 xray / sing-box。配置只回传 SHA-256、大小、入出站 / 路由计数与校验结果；最近 15 分钟最多 200 条本项目 journal 仅本地分类。无原始配置 / 日志 / 任意路径 / 命令入口，失败与截断标未知；读取及回执重试不得重启内核。

证书批量绑定

管理员选择同一 Gate 有效证书和 TLS 入站，certificate.bind.v1 单任务至多 100 项。中心 / Agent 校验旧绑定、TLS、有效期与 SNI，任一失败不部分修改；落盘配置整体预检与恢复沿用现有 apply。回执前不修改已生效列表；保留端口、凭据与启停状态。
