01产品边界

会话已确认
能力管理员普通用户
用户创建、停用、额度与有效期管理全部查看自己的数据
Gate 配对、入站、客户端、路由与内核运维管理与授权无权限
订阅源、节点、订阅组、处理链、模板、公开页设置统一管理仅获取已授权结果
流量、到期时间、订阅链接与二维码查看与分配仅自己
安全告警、审计、模型地址与密钥管理全部无权限
授权的最小单位：Gate + 入站。 每个用户获得独立客户端凭证；默认复用入站。用户生成订阅不创建入站、不增加授权、不下达管理指令。
重点：后台与 VPS 防入侵用户：机场式自助中心当前：全 Go Monorepo 实施支付 / 计费商城未纳入

04安全与判断

规则执行 · 模型辅助

人的身份

管理员登录二次验证；后端角色检查；用户数据按身份隔离。

登录限速、会话撤销、恢复机制。2FA 与设备配对是两套认证。

设备的身份

VPS 发起配对；一次性短时凭证；独立设备身份，可单独撤销。

主动出站连接、操作白名单、拒绝重放与跨设备指令。

行为的证据

记录谁、何时、对哪台设备、做了什么，以及执行结果。

中心与本地留痕；敏感信息脱敏。未知状态不能显示正常。

Laya：脱敏事件 → 远程 API → 分类与告警优先级。密钥仅后台持有；模型不能授予权限或直接执行命令；超时仍保留规则告警与事件记录。评分不是攻击事实，需真实样本验证。

复用依据

Sub2API优先复用用户、认证、审计后端及测试；UX 参考其布局和管理流程。当前许可 LGPL-3.0，迁入时保留声明并核对分发义务。

MiGateGo 执行端、内核管理、客户端凭证与流量采集。旧代码已完整备份；复用时核对逐文件来源。
UIAbleReact 组件源码优先。开源仓库为 MIT；实际选用条目与依赖另记清单，剥离 Next.js 专属依赖以适配 Vite。
Laya仅接远程服务，不部署模型。原生 Jev 协议与 Bearer Key；不能假设普通聊天网关自动兼容。

实施选型

D02已定：中心预算分配，默认 32 MiB，低于 25% 补充；离线耗尽暂停，未结算不重发。
D03已定：设备独立密钥，HTTPS 20 秒长轮询；幂等任务与回执。
D04已定：后台配置 TOTP / Passkey / SMTP，注册开关默认关闭；新用户无默认授权。
